Protocol Foundations & Evidentiary Gap

The UCP Trust Shift: From Promises to Cryptographic Proof

UCP solves N-to-N capability negotiation, but open protocols alone do not guarantee institutional trust. Proof-of-Control establishes verifiable evidence at every protocol transition.

⚠️ The Evidentiary Gap
Baseline UCP allows unsigned requests, mutable server logs, and non-pinned schemas. If a dispute occurs, counterparties cannot independently prove authority or state after the fact.
Requires session-pinned profile snapshots & JWK keys.
⚙️ Outside-the-LLM Control Gates
LLMs must never control checkout state transitions. When checkout returns requires_escalation, the platform agent is deterministically blocked from completion and forced to hand off to continue_url.
Zero-tolerance for escalation bypasses.
🔏 AP2 Dual Mandate Cryptography
Autonomous purchases require Selective Disclosure JWTs (SD-JWT) key-bound to user identity: both an ap2.checkout_mandate and a correlated payment token with 6-parameter binding.
Non-repudiable authority for autonomous agents.
Comprehensive Threat Modeling

MAESTRO 7-Layer Defense for Agentic Commerce

Mapping Cloud Security Alliance's MAESTRO model to UCP surfaces to establish verifiable invariants against hallucinations, state manipulation, and replay attacks.

L7: Ecosystem & Counterparties High Risk
Threat: Rogue agents, payment credential replay across merchants.
Proof: AP2 SD-JWT dual mandates; payment bound to 6-tuple; SBOM/SLSA vetting.
L6: Governance & Compliance Policy
Threat: Pre-release draft downgrade attacks; overbroad OAuth scopes.
Proof: Date versions (YYYY-MM-DD); signed leaf profiles; OAuth PKCE S256 mapping.
L5: Observability & Audit Logs Audit
Threat: Post-dispute log deletion/reordering; forged webhook order events.
Proof: RFC 9421 HTTP Message Signatures; signer-to-order ownership verification.
L4: Infrastructure & Transports Infra
Threat: Profile SSRF/redirect substitution; gateway Content-Digest reserialization.
Proof: HTTPS-only no-redirect fetch; HSM/KMS keys; TEE remote attestation.
L3: Agent Framework & State Protocol
Threat: Orphaned extensions; namespace spoofing; requires_escalation bypass.
Proof: Reverse-domain checks; formal state machine; signed negotiation transcript.
L2: Data Operations & Signals Data
Threat: Poisoned catalog feeds; stale pricing; unverified buyer-asserted signals.
Proof: Merkle catalog state; signed signal attestations; consent-to-policy logs.
L1: Foundation Models Reasoning
Threat: Prompt injection altering commerce terms; model version drift.
Proof: Signed model/policy manifests; deterministic execution outside the LLM.
