# Proof-of-Control Assurance Framework for Universal Commerce Protocol (UCP)

Interactive presentation deck detailing the Proof-of-Control assurance framework for agentic commerce powered by the Universal Commerce Protocol (UCP) and Cloud Security Alliance's (CSA) MAESTRO 7-layer threat modeling standard.

- **Speaker Slide:** https://kenhuangus.github.io/ucp-slides/#2

## Overview

The Universal Commerce Protocol (UCP) provides open capability negotiation across platforms, merchants of record, and payment service providers. However, open protocols alone do not guarantee verifiable trust. 

Proof-of-Control closes this evidentiary gap by shifting assurance from unilateral platform promises and post-hoc audit reconstruction to cryptographic evidence generated at the exact moment of commerce action.
